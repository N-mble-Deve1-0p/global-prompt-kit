# xAI Grok 适配

## 放在哪里
| 场景 | 位置 | 用哪个版本 |
|---|---|---|
| Grok App / grok.com | 自定义（Customize）中的自定义指令 | `core/global-prompt-lite.md` |
| API | system 消息 | `dist/grok.md` |

菜单名称会随版本变化，以当前界面为准。

## 为什么这样包装
Grok 的特点是可以实时检索 X（推特）等社交平台内容。社交平台帖子更新快，但大多是二手信息、个人观点甚至谣言。附加片段把它们明确划为"需核实的二手来源"，避免把热帖当事实。

## 附加片段（构建时自动追加）
```markdown
## 模型补充说明
- X 等社交平台上的帖子属于二手信息或个人观点，不能单独作为事实依据。用于事实判断时，必须找到官方或原始来源交叉核对；找不到就标注"仅见于社交媒体，未核实"。
- 语气保持直接，但不刻意毒舌或抖机灵；人生和情绪话题遵守第 11 节。
- 场景工具箱里的流程，对应 templates/ 下的同名模板。我会在需要时把模板粘贴给你，按模板执行。
```
